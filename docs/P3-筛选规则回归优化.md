# P3：筛选规则回归优化

## 目标与边界

P3 的目标是只推送仍可申报、提名、推荐、参评或报名的规划/建设行业奖项与竞赛机会。获奖结果、名单公示、网络人气投票、评审结果、会议培训、基金课题、项目指南、专家库和非行业奖项均不推送。

生产链路变为：详情补充 → P3 标题门禁 → 关键词初筛 → AI 结构化核验 → 飞书通知。标题门禁只拒绝标题已能确定无关的记录；不确定的行业相关性、截止日期和申报条件仍交 AI 与详情正文判断。

## 改动

- `filters/title_gate.py`：拒绝结果公示、非奖项机会、非行业奖项、标题年度明显过期和网络投票；行业协会的奖项/竞赛通知保留给 AI。
- `filters/ai_filter.py`：提示词升级为 `p3-v1`，要求同时确认行业相关性、申报动作和可行动性，并列出高频误报类型与风景园林竞赛正例。
- `config.yaml` 与 `config.yaml.example`：新增关键词 `竞赛`，避免职业技能竞赛和设计竞赛在关键词阶段漏掉。
- `tests/fixtures/p3_event_time_regressions.csv`：冻结 45 条历史误报及 7 条历史漏报；自动化测试要求标题门禁拒绝至少 43 条误报且保留全部 7 条漏报给 AI。

## 离线回放

使用 `qwen3.5:latest`、2 路并发，对 P2 事件时点队列做只读回放。标题门禁仅让 14/295 条进入 AI；结果为加权精确率 94.26%、召回率 73.25%、F1 82.44%。产物位于 `data/reports/P3事件时点离线回放_20260710.*`。

该结果基于历史标题和少量存档信息；历史记录没有正文，不能替代含详情正文的正式运行验证。后续正式运行应只读核对标题门禁拒绝原因、AI 结构化结果和飞书展示，不得为验证手动发送真实通知。
